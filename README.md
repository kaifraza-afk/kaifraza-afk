### 🚀 Featured: What Broke, and What I Learned

<table>
<tr>
<td width="50%" valign="top">

**🤖 RAG Support Agent**

An AI support agent with retrieval, tool-calling, and confidence-based escalation. Deployed, working, felt done.

Then the underlying Gemini model got **deprecated mid-flight** — and the new model's embedding dimensions didn't match my vector store. Everything silently broke.

I re-embedded the entire knowledge base and rebuilt the retrieval pipeline around a versioning strategy so it wouldn't happen blind again.

**Lesson:** shipping AI isn't the finish line — the infrastructure moves under you, and good systems are designed to notice when it does.

`Python` `FastAPI` `LangChain` `ChromaDB` `React` `Docker`

</td>
<td width="50%" valign="top">

**🏥 Dantewada Health Analytics**

Full-stack analytics platform turning fragmented healthcare data into something a real hospital administrator can use.

- 2.18 lakh+ patient records processed
- 18 disparate source files unified into one system
- Built for actual use by healthcare officials, not a portfolio demo

**Lesson:** the hardest part of "AI for good" isn't the model — it's making messy, real-world data usable by someone who isn't technical.

`React` `Node.js` `PostgreSQL` `Prisma`

</td>

### 🧩 How I Think About AI Systems

```
AI APPLICATION
      │
┌─────┴─────┐
│ UI │ API Layer │
└─────┬─────┘
AI Orchestrator
      │
┌────┼────┐
LLM  RAG  Tools
      │
  Evaluation  ← this is the step most people skip
      │
 AI Response
```

I care most about the **Evaluation** layer — an AI feature that isn't measured against real user outcomes is just a demo with good vibes.
